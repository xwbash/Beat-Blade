# Beat and Blade — A Rhythm Game Without VR 🎵⚔️

**What if you could experience VR-inspired rhythm gameplay using just your keyboard and mouse?**

That's the question that started this little experiment.

I'm a solo game developer at **GorillaDev**, and I love games like Beat Saber. Unfortunately, not everyone has a VR headset, so I wanted to see if I could create something with a similar feeling that anyone with a PC could try.

And well... here we are!

## 🎮 How It Works

The game combines two different mechanics:

- **Left Hand — WASD:** Hit incoming rhythm notes using your keyboard.
- **Right Hand — Mouse:** Control a sword and slice incoming blocks with smooth, curved movements.

Both hands work simultaneously, creating a challenging and surprisingly fun coordination-based rhythm experience.

No VR headset required!

## 🎶 Custom Beatmap Support

The game supports importing compatible community-made Beat Saber beatmaps from [BeatSaver](https://beatsaver.com).

Download a compatible map, import it into the game, and start playing!

*Compatibility is still experimental. Not every beatmap is guaranteed to work. Music and beatmaps remain subject to their respective licenses and copyrights.*

## 🤖 Built With AI

This project was developed with AI assistance.

Instead of spending months building a complete game, I wanted to quickly prototype an idea and find out whether the core gameplay was actually fun.

AI helped accelerate the development process, allowing me to focus on experimenting with the mechanics and overall game feel.
